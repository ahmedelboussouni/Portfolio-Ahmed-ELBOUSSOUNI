# Portfolio React — Ahmed ELBOUSSOUNI

Portfolio personnel développé avec React et Vite.

## Installation du projet

**1. Cloner le projet depuis GitHub :**

```bash
git clone https://github.com/ahmedelboussouni/Portfolio-Ahmed-ELBOUSSOUNI.git
```

**2. Accéder au dossier du projet :**

```bash
cd Portfolio-Ahmed-ELBOUSSOUNI
```

**3. Installer les dépendances :**

```bash
npm install
```

**4. Démarrer le projet :**

```bash
npm run dev
```

**5.** Ouvrir dans le navigateur l'adresse localhost affichée dans le terminal.

## Technologies

React • Vite • JavaScript • CSS
